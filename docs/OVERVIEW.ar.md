# LexiCore-5000 — نظرة عامة (العربية)

> نسخة مختصرة من README لأغراض الوصف. النص المرجعي هو الإنجليزي، وكل رقم هنا قابل للتحقق من
> الملفات نفسها بواسطة `make validate`.

**LexiCore-5000** قائمة كلمات إنجليزية أساسية من **5,000 كلمة**، موزّعة على خمسة مستويات CEFR
بواقع **1,000 كلمة لكل مستوى** (A1 وA2 وB1 وB2 وC1). بُنيت بالعدّ الفعلي داخل خمسة متون مجموعها
**13,632,611,970 كلمة**، ثم اختيرت الكلمات بدرجة مرجّحة تجمع: التكرار (0.34)، وانتشار الكلمة بين
المستندات (0.18)، والمنفعة التعليمية وفق قوائم NGSL/NAWL/BSL (0.18)، وتوازن الظهور عبر المصادر
(0.10)، والمدى (0.08)، ونسبة المستندات (0.06)، والحداثة (0.06).

| | |
|---|---|
| الكلمات | 5,000 فريدة، كلمة واحدة لكل مدخل، بأحرف صغيرة |
| ورودها في المصادر الخمسة كلها | 4,953 كلمة (99.06%)، وفي أربعة مصادر فأكثر 99.98% |
| مصدر المستوى | CEFR-J v1.5 لـ 3,898 · Octanove لـ 665 · نموذج إحصائي لـ 437 |
| المقارنة بأكسفورد 5000 | تقاطع 3,526 (70.5%)، Jaccard 0.5508، كابّا تربيعي 0.7124 |

## الملفات

* `data/LexiCore_5000.csv` — القائمة الأصلية: الترتيب، المستوى، مصدر الوسم، الثقة، عدد المصادر،
  عدد الورود، وخطّ الأساس `wordfreq` (Zipf 2021).
* `data/lists/A1.txt` … `C1.txt` — قوائم جاهزة للطباعة لكل مستوى (بالترتيب ومرتبة أبجديًا).
* `data/derived/` — **المرشحون الـ 215,416 كاملون** مع سماتهم، أي يمكنك إعادة الاختيار بأوزانك دون
  إعادة معالجة المتون: `python -m lexicore reweight --freq 0.5 --disp 0.25 …`
* `data/MANIFEST.json` — مصادر البيانات مع رابط كل ملف وحجمه وبصمته SHA-256.
* `reports/upstream/` — تقارير الإنتاج الأصلية وسجلّات المراحل كما هي دون تعديل.

## ما يجب أن تعرفه قبل الاستخدام

نحن ننشر عيوب القائمة مع مزاياها، ومفصّلة في [docs/KNOWN_ISSUES.md](KNOWN_ISSUES.md):

1. **البعد الزمني لم يُحسب:** الحقلان `recent_share_2022plus` و`newest_share_2025_2026` فارغتان في
   5,000/5,000 صفًا، لذلك **لا تصف الإصدار 1.0.0 بأنه «مرتّب حسب الحداثة»**.
2. **حقل `pos` غير موثوق:** جاء من بحث معجمي لا من وسمٍ سياقي، لذلك تظهر كلمات مثل `at` و`be`
   بأنها `noun`، و72% من القائمة موسومة noun.
3. **437 كلمة مستواها من نموذج** دقّته في التحقق المتقاطع 0.3814 (بينما الفئة الأغلبية وحدها ≈0.32).
4. **مستوى C1 سلة فائض:** المرشحون فيه 97,963 مقابل 13,808 في B2، فليس له معنى «أندر» صارم.
5. **الترتيب داخل المستوى ليس ترتيبًا تكراريًا:** أول A1 هي `at` لا `the`؛ للحصول على ترتيب التكرار
   استخدم `python -m lexicore words --level A1 --sort freq`.

## المنتج المرافق

**LexiDeck Multilingual** رزمة أنكي مبنية على هذه القائمة **مع إضافة نحو 700 كلمة** (الإجمالي
≈5,700 كلمة من A1 إلى C1)، خمسة أمثلة لكل كلمة تدور أثناء المراجعة، وصوت بشري للجمل وللكلمات،
ونطق IPA، وصورة لكل كلمة، وترجمات إلى 12 لغة. الوصف الكامل والروابط ولقطات الشاشة في
[ecosystem/lexideck-multilingual/](../ecosystem/lexideck-multilingual/)، وبنية البطاقات مقاسةً على
العيّنة المجانية في [DECK_STRUCTURE.md](../ecosystem/lexideck-multilingual/DECK_STRUCTURE.md).

## للمطوّرين

```bash
git clone https://github.com/X-Trivle/LexiCore.git && cd LexiCore
make install && make validate && make test && make lint
```

كل تعديل تحت `data/` يمرّ بقضية (issue) أولًا، ثم يُعاد توليد سجلّ البصمات في طلب التغيير نفسه
(`make ledger`)؛ وبذلك يستحيل أي تعديل صامت على القائمة. راجع [CONTRIBUTING.md](../CONTRIBUTING.md).
